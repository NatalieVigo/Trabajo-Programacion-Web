# Mesa de ayuda de servicios del campus

Proyecto del curso de Programación Web de la Universidad de Lima.

Este es un avance del proyecto: por ahora solo tiene el front-end, hecho con React y Vite. Los datos son de prueba y se guardan en el navegador.

## Cómo probarlo

Se necesita tener Node.js instalado.

```
git clone https://github.com/NatalieVigo/Trabajo-Programacion-Web.git
cd Trabajo-Programacion-Web/frontend
npm install
npm run dev
```

Luego abre http://localhost:5173 en el navegador.
