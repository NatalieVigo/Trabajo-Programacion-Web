# Mesa de ayuda de servicios del campus

Proyecto del curso de Programación Web de la Universidad de Lima.

Este repositorio tiene el front-end, hecho con React y Vite. Todas las historias, de HU-1 (cuenta y acceso) a HU-7 (métricas y usuarios), usan la API REST, que está en el repositorio [Trabajo-Programacion-Web-backend](https://github.com/NatalieVigo/Trabajo-Programacion-Web-backend).

## Cómo probarlo

Se necesita tener Node.js instalado.

```
git clone https://github.com/NatalieVigo/Trabajo-Programacion-Web.git
cd Trabajo-Programacion-Web/frontend
npm install
npm run dev
```

Luego abre http://localhost:5173 en el navegador.

Para iniciar sesión la API debe estar encendida: sigue los pasos del README de [Trabajo-Programacion-Web-backend](https://github.com/NatalieVigo/Trabajo-Programacion-Web-backend).
